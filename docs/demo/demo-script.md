# 演示录屏脚本（60–90 秒）

用于 GitHub Release 附件、官方市场插件详情页、报名表「作品链接」。

## 录屏前准备

1. DSH 已安装本插件并通过 Plugin Manager 启用（或 profile patch 挂载）；
2. `$DSH_HOME/token-usage-prices.json` 已填入真实单价（**不要**录到真实价格也可以，但界面要显示金额而不是「未定价」）；
3. 准备一个**已有若干轮对话、且包含一次子代理调用**的会话；
4. 关闭无关窗口、通知；不要出现 API Key、私有仓库路径、真实项目名；
5. 录制工具：Windows 自带 `Win + Alt + R`（Xbox Game Bar，输出 MP4 到「视频/捕获」），或 OBS。

## 分镜

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0–6s | 打开 DSH Web GUI，左侧边栏可见「用量与成本」图标 | 插件装好后，侧边栏多出「用量与成本」入口 |
| 6–14s | 点击进入整页：顶部四个汇总卡片（累计 tokens / 累计花费 / 今日花费 / 会话数） | 一眼看到累计用量和花费 |
| 14–22s | 鼠标滑过时间范围选择，切到「近 7 天」再切回「全部」，表格随之重算 | 时间范围切换，卡片和表格一起重算 |
| 22–34s | 滚动到「日 × 模型」表，展开某个月的折叠行；展示 token 四个桶与金额 | 按日 × 模型拆分：输入、缓存读、缓存写、输出 |
| 34–44s | 切到「按对话」表，指出某行子代理会话已合并进主对话 | 子代理会话自动合并，多 agent 对话不会少算 |
| 44–52s | 输入框下方花费胶囊：点击展开，显示本对话 token 与花费 | 对话内的花费胶囊，随时查看当前对话成本 |
| 52–62s | 点击「导出 CSV」，用 Excel 打开其中一张表 | 一键导出 CSV，Excel 直接打开 |
| 62–72s | 打开 `%USERPROFILE%\.dsh\token-usage-prices.json`，改一个单价，回到页面点刷新 | 单价自己填，改动立即生效，升级不会覆盖 |
| 72–80s | 定格：侧边栏 + 页面全貌 | dsh-token-cost-report · 用量与成本，一目了然 |

## 导出与命名

- 文件名：`dsh-token-cost-report-demo.mp4`（≤ 10 MB，≤ 90 秒）；
- 也可额外导出 2–3 张 PNG 截图：`docs/demo/page.png`、`chip.png`、`csv.png`；
- 上传位置：GitHub Release 的 `v0.2.0` 附件，README 里用 `![demo](docs/demo/page.png)` 引用截图；
- 报名表「作品链接」填：npm 页面 + GitHub 仓库 +（可选）演示视频直链。

## 口播短版（15 秒，适合无声字幕）

> DSH 装了这个插件，就能看到每天、每个模型用了多少 token、花了多少钱；
> 对话里直接显示本次花费，子代理会话自动合并；
> 峰谷价、时间范围、CSV 导出都有，单价自己填，升级不覆盖。
